1. Website Vision

The Marudeni Foods website should function as a premium digital storefront for ordering food, discovering the brand, and requesting catering services. The experience should feel elegant, warm, trustworthy and distinctly Nigerian while remaining simple enough for customers to place an order quickly.

Primary Goals

GOAL

REQUIREMENT

Sell food online

Customers browse products, select quantities, add items to cart and review their order.

Simple checkout

Checkout uses bank transfer for now, with the final order sent to WhatsApp for confirmation.

Build trust

Use strong food photography, hygiene/safety messaging, brand story and clear contact details.

Generate catering leads

Dedicated catering page and enquiry flow for events, corporate orders and private functions.

Prepare for growth

Structure the system so online payment gateways, delivery tracking and more automation can be added later.

5. Food Ordering & Cart System

The core ordering experience should be fast and mobile-first because many customers will likely order from a phone.

1. Customer opens Menu / Order.

2. Customer selects a category and views food items.

3. Customer opens a product, selects quantity/options where applicable, and taps Add to Cart.

4. Cart drawer/page shows items, quantities, prices and subtotal.

5. Customer proceeds to Checkout.

6. Customer enters name, phone number, delivery/pickup preference, address where required, and optional order note.

7. Website displays bank-transfer payment instructions.

8. Customer taps “Confirm Order on WhatsApp”.

9. WhatsApp opens with a pre-filled order message containing order reference, items, quantities, total and customer details.

10. Marudeni confirms payment and order fulfilment manually for the initial phase.

Cart requirements

Increase/decrease quantity.

Remove item.

Display item price and line total.

Display subtotal and any applicable delivery fee.

Optional customer order note.

Persist cart during the current browsing session.

Clear cart after successful order submission.

6. Bank Transfer + WhatsApp Checkout

For Phase 1, the website does not need an online card/payment gateway. Instead, the system should generate a clear bank-transfer instruction and then move the customer to WhatsApp for order confirmation.

CHECKOUT ELEMENT

RECOMMENDATION

Order Reference

Generate a unique reference such as MRD-2026-0001.

Payment Details

Show Marudeni's approved bank name, account name and account number. These details should be editable from the admin area.

Amount

Clearly display the exact order total the customer should transfer.

Proof of Payment

Optional Phase 1 approach: customer sends transfer proof through WhatsApp.

WhatsApp Message

Auto-compose a structured order message rather than asking customers to type the order manually.

Order Status

Use Pending Payment → Payment Confirmed → Preparing → Ready/Dispatched → Completed.

Important: payment instructions should be centrally editable so the website does not need a code deployment whenever Marudeni changes its bank account.

8. Admin / Content Management

A simple admin dashboard is recommended so Marudeni can manage the business without depending on a developer for everyday updates.

Products: create, edit, archive, price, image, category, description and availability.

Categories: manage food categories and display order.

Orders: view order reference, customer details, items, amount, payment status and fulfilment status.

Bank details: update bank name, account name and account number.

Catering enquiries: view, update status and export/contact leads.

Homepage content: featured products, promotional banners and selected text.

Business settings: WhatsApp number, phone number, social links and operating information.

10. UI / UX Direction

PRINCIPLE

IMPLEMENTATION

Premium, not crowded

Use generous spacing, large food photography, restrained gold accents and strong typography.

Mobile-first

Cart, menu filters, buttons and checkout must work comfortably on small screens.

Photography-led

Food should be the visual hero. Avoid excessive decorative graphics that compete with food images.

Clear CTAs

Use consistent actions: Order Now, Add to Cart, View Cart, Checkout, Request Catering Quote, Chat on WhatsApp.

Trust at checkout

Show clear totals, payment instructions, contact support and order reference.

Fast ordering

A customer should be able to go from homepage to cart with minimal steps.

11. Technical Recommendation

The website can be implemented as a modern responsive web application with a database-backed admin area. The architecture should keep the ordering, catalogue and catering modules separate enough to support future growth.

AREA

RECOMMENDATION

Frontend

Next.js / React with responsive UI and strong SEO support.

Styling

Tailwind CSS or an equivalent design system using the Marudeni palette.

Backend

Next.js server/API layer or a dedicated Node.js API where appropriate.

Database

MySQL or PostgreSQL for products, orders, customers, catering enquiries and settings.

Images

Optimised cloud image storage/CDN for food and gallery photography.

WhatsApp

Click-to-chat with dynamically generated order/enquiry messages.

Authentication

Secure admin authentication with role-based access if multiple staff will manage the system.

Payments

Phase 1 bank transfer; design checkout service so a gateway such as Paystack/Flutterwave can be added later without rebuilding the storefront.

Hosting

Deploy on a reliable cloud platform with SSL, backups and environment-variable based configuration.

15. Definition of a Successful First Version

The first production version is successful when a customer can discover Marudeni Foods, browse the menu, add multiple food items to a cart, see an accurate total, receive bank-transfer instructions, submit the order through WhatsApp, and contact Marudeni for support — while a separate visitor can request catering services without needing to call first.
